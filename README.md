# Comut-Share

Corporate Carpool Platform built for Karachi commuters. Connects office employees travelling on overlapping routes to share rides, split fuel costs fairly, and build a trusted commuter community.

## Project Structure
- **/web**: Next.js 16 landing page and corporate web dashboard.
- **/backend**: Express & TypeScript REST API services.
- **/mobile**: Flutter mobile app for on-the-road commute matching and escrow boarding codes.
